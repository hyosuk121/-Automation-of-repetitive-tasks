# 항공 과거·일별 자료 자동 연계 조사

기준일: 2026-11-23 (Asia/Seoul)

## 현재 연결된 공식 API

공공데이터포털의 `인천국제공항공사_항공사별 노선별 운송실적` API는 승인·키 설정·실응답 보관까지 확인했다. 2026년 9월 469행을 보관하고 있으며, 서버는 매일 09:00 KST 이후 해당 API를 확인한다. 이 API의 요청변수에는 실적 연월·일자를 지정하는 항목이 없다. 응답도 월간 실적이다. 따라서 매일 확인한다고 일별 실적이 생기거나 2021년 자료를 소급 조회할 수는 없다.

실응답에는 국가 누락 1행과 동일 식별조건의 서로 다른 수치 2쌍이 있었다. 현재 차트는 해당 행을 제외한 유임승객 부분합이며 확정 총여객 통계가 아니다.

## 과거 월간 후보

- 항공포털 [국가·지역 월간 통계](https://www.airportal.go.kr/stats/transport/chartDetail4.do) 및 [월간 시계열](https://www.airportal.go.kr/stats/transport/chartDetail5.do): 원래 인계 문서에서 연월 선택과 다운로드가 가능한 웹 화면으로 확인했다.
- 공공데이터포털 [공항별 항공통계 파일데이터](https://www.data.go.kr/data/15092537/fileData.do): 파일 단위 후보로 기록돼 있다.

자동 연계 전에 **공식 기계 판독 주소와 파일/응답 명세**를 확인해야 한다. 특히 2021년부터 최근까지의 모든 월, 인천공항만, 출발, 국제선, 국가/지역 구분, 유임·무임·환승 정의가 필요하다. 파일이 공식 안정 URL로 제공된다면 서버가 정기 다운로드할 수 있으므로 매번 엑셀 업로드할 필요는 없다. 다만 현재 확인된 정보만으로 파일 주소·컬럼·갱신 규칙을 추측해 수집기를 작성할 수 없다.

## 일별 후보

- 항공포털 [일자별 노선 통계](https://www.airportal.go.kr/stats/transport/dailyRoute.do): 원래 인계 문서는 2026-11-12 인천공항 국제선 하루 실적을 웹 화면에서 조회했다고 기록한다. 약 7일 지연 자료이며, 최근 7일은 조회 불가로 표시됐었다.
- [일자별 공항 운항 통계](https://www.airportal.go.kr/stats/transport/liveAirplane.do): 화면 후보. 국가별 출발 여객 실적을 제공하는지는 확인되지 않았다.

화면 조회 가능 여부와 서버에서 합법적으로 자동 호출할 수 있는 **공식 API/다운로드 경로**는 별개다. 호출 조건, 기간 제한, 페이징, 국가 코드, 수정·누락 처리, 이용약관을 확인한 뒤 일별 저장·7일/28일 비교를 구현해야 한다.

## 이번 환경에서 확인한 한계

Codex 실행 환경에서 data.go.kr, airport.kr, kosis.kr의 HTTPS 접속은 모두 프록시 `CONNECT 403`으로 막혔다. 읽기 전용 외부 실행 승인 경로로 다시 시도해도 동일했다. 이는 운영 Vercel 서버의 응답 실패가 아니다. 현재 자료에서 검증되지 않은 API나 브라우저 내부 호출을 서비스에 붙이지 않았다.

## 다음 연결 작업의 완료 기준

1. 제공기관의 공식 API 활용가이드 또는 고정 다운로드 URL과 실제 응답 예시 확보.
2. 기간·공항·출발·국제선·국가·여객 필드와 이용 조건을 대조. 현재 월간 API와 집계 기준이 다른 경우 별도 출처로 저장하고 서로 합산하지 않음.
3. 과거 자료는 2021년부터 확보 가능한 월만 초기 적재하고, 원천 수정은 버전으로 보관. 누락 월을 0으로 채우지 않음.
4. 일별 자료는 실적일과 확인일을 분리하고, 게시 지연·누락·정정을 저장. 실제 연속 일수가 확보됐을 때만 7일/28일 비교를 계산.
5. 원천 행과 개인 메모는 관리자 전용으로 유지. 품질 검증된 집계만 공개 조회 가능하게 함.

현재 사용자가 키를 다시 전달할 필요는 없다. 새 공식 소스의 활용 신청이 필요하다고 확인된 경우에만 해당 소스의 신청 안내를 제공한다.
