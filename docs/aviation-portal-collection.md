# 항공정보포털 과거·일별 자동 수집

기준: 2026-11-25 (Asia/Seoul)

기존 인천공항 월간 OpenAPI와 별개로 항공정보포털의 공개 통계 화면이 사용하는 조회 경로를 확인했다. GitHub Actions의 일회성 공개 페이지 검사에서 로그인 없이 다음 실제 응답을 검증했다. 이 경로는 공개 웹 화면의 조회 방식이며 별도 공인 OpenAPI 계약을 뜻하지 않는다. 제공기관이 응답 형식이나 이용 조건을 변경하면 수집기가 실패 상태로 남고 이전 저장 자료는 유지된다.

| 자료 | 공개 화면 | 조회 조건 | 검증된 예시 |
|---|---|---|---|
| 과거 월간 | [노선 상세 통계](https://www.airportal.go.kr/stats/transport/chartDetail3.do) | 인천 ICN, 국제선 I, 출발 D, 유임여객 1, 여객기 Y, 한 달씩 | 2021.01: 82행·유임 94,634명; 2026.09: 165행·유임 2,725,422명 |
| 최근 일별 | [일자별 노선 통계](https://www.airportal.go.kr/stats/transport/dailyRoute.do) | 인천 RKSI, 국제선 I, 실적일 하루씩 | 2026.11.12: 424행·출발 여객 106,135명 |

월간 노선별 개별 합계가 각 응답의 전체 합계와 일치했고, 일별 샘플의 상대 공항 424건 모두 국가에 연결됐다. 월간 **유임여객**과 일별 **출발 여객**은 정의가 달라 서로 합산하거나 같은 그래프로 연결하지 않는다. 일별 값은 당일 수요가 아니라 공개 시차가 있는 실적일 값이다.

상대 공항의 IATA/ICAO 코드에서 국가·지역을 찾기 위해 [OurAirports 기반 airport-codes 데이터](https://github.com/datasets/airport-codes)를 2026-11-23 기준으로 축약한 매핑을 사용한다. 해당 패키지는 ODC-PDDL-1.0으로 안내되며 원 출처와 코드 목록의 재사용 조건에 관한 설명도 [datapackage.json](https://github.com/datasets/airport-codes/blob/master/datapackage.json)에 있다. 매핑이 없는 공항은 추정하지 않고 검토 상태로 보관한다.

기존 Supabase Cron이 5분 간격으로 작업을 호출한다. 오전 9시(KST) 이후 남은 실행 시간이 충분하면 매 호출에서 일별 하루와 월간 한 달을 확인한다. 일별은 최근 70일을, 월간은 2021.01부터 지난달까지의 비어 있는 월을 자동으로 채운다. 최근 날짜/월은 다음 날 재확인하고 정정 응답을 새 스냅샷으로 누적한다. 한 번에 많은 요청을 보내지 않는다. 빈 응답은 0명으로 저장하지 않고 하루 뒤 재확인한다.

관리자 화면의 ‘자료 수집 실행’은 자동 작업 한 회를 직접 실행한다. 운영 중 자료를 보려고 브라우저를 계속 열어 둘 필요가 없다. 개인 메모 및 원천 행은 관리자 전용이다. 현재 화면의 항공정보포털 수치는 제공된 노선 행을 코드로 묶은 관측값이며, 사이트 전체 통계와 지속적으로 대조해야 한다.
